# Tutorial estático para GitHub Pages

Este projeto contém uma página única (`index.html`) para tutorial de material suplementar científico.

## Estrutura

- `index.html`: conteúdo da página
- `styles.css`: estilos visuais

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie estes arquivos para a branch `main`.
3. No GitHub, vá em **Settings > Pages**.
4. Em **Source**, selecione **Deploy from a branch**.
5. Escolha `main` e pasta `/ (root)`.
6. Salve e aguarde o deploy.

A URL final será algo como:

`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

## Se quiser anonimizar depois

- Use conta GitHub neutra (sem nome/foto/bio pessoal).
- Não inclua nomes de autores, instituição, links pessoais ou analytics.
- Remova metadados de imagens/PDFs antes de subir.
- Use histórico de commits novo (sem reaproveitar histórico pessoal).
