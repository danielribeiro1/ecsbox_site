Tutorial de Reprodução

Esta página descreve o passo a passo para reproduzir os resultados do estudo.

1. Requisitos

  • Sistema operacional compatível (Linux, macOS ou Windows).
  • Dependências instaladas conforme descrito no artigo.
  • Acesso aos dados e scripts suplementares.

2. Preparação do Ambiente

  1. Baixe os arquivos suplementares do repositório informado no artigo.
  2. Crie um ambiente isolado para execução.
  3. Instale as dependências listadas na documentação do projeto.

3. Execução

  1. Execute o script principal com os parâmetros padrão.
  2. Gere os resultados intermediários e salve em pasta dedicada.
  3. Rode o script de análise para produzir métricas e figuras finais.

4. Verificação

Compare os artefatos gerados (tabelas, métricas e figuras) com os resultados reportados no artigo. Diferenças pequenas podem ocorrer por variações de ambiente.

5. Citação

Para citação, utilize os dados bibliográficos apresentados no manuscrito submetido.
